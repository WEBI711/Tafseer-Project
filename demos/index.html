Design directions

Tafseer — six visual languages

Each demo is a single self-contained file with four working views — Read · Browse · Search · Chat — rendering the same corpus (Juz 1: Al-Fatihah & Al-Baqarah, 52 ayat, 267 passages). Click the tabs in any demo to move between them and compare how each visual language handles the same jobs.
